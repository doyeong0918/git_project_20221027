로또 생성기 웹 문서 만들기
목적: 버튼을 누르면 1~45중 중복 없는 6개의 번호 뽑아 화면에 보여주는 웹 
기능: 내가 번호뽑기 버튼을 누르면 6개의 공이 화면에서 돌아가면서 뽑히고 숫자를 오름차순으로 정렬해서 화면에 보여줘
입력: 사용자가 버튼 클릭
출력: 번호찍힌 공 모양으로 뽑힌 번호 출력, 생성횟수
제약: html, css, js만을 사용해서 만들어줘, 외부라이브러리 사용하지말고 해줘, 파일이름은 lotto.html 으로 해줘, 
      함수와 변수에 주석을 달아서 초보자도 이게 무엇인지 상세하게 달아줘
확인기준: 번호 6개가 항상나오는지 확인, 1~45까지 번호가 나오는지 확인, 초기화 버튼 확인
